**Penguins MLOps Pipeline — PMLDL Assignment 1**

Automated ML pipeline running every 5 minutes with Airflow:

**Data Engineering → Model Engineering → Deployment**

Cleans the Palmer Penguins dataset, trains a classifier, logs metrics to MLflow, and redeploys the model as a FastAPI service with a Streamlit web app — each in its own Docker container.

| Stage | Operations | Artifacts |
|-|-|-|
| 1. Data	clean, impute, remove IQR outliers | train/test split | data/processed/*.csv |
| 2. Model	one-hot + scaling, Logistic Regression | metrics → MLflow | models/model.pkl
| 3. Deploy	rebuild & restart | Docker containers with the fresh mode | API :8000, app :8501

**How to run**

```bash
git clone https://github.com/dariapotapova/PMLDL_Assignment1
```

```bash
docker compose -f services/airflow/docker-compose.yml up -d --build
```
The DAG starts automatically and runs on every 5-minute boundary.

Manual trigger: Airflow UI → penguins_pipeline → ▶, or:

```bash
docker compose -f services/airflow/docker-compose.yml \  exec airflow-scheduler airflow dags trigger penguins_pipeline
```

**Notes**\
data/processed/, models/, mlruns/ are generated by the pipeline — no need to clone them.\
The model artifact is a full sklearn Pipeline (preprocessing + classifier), so the API applies identical transformations to training — no train/serve skew.\
ML stack versions are pinned identically in the Airflow and API images (pickle compatibility).\
If a cycle exceeds 5 minutes on your machine, change the schedule in services/airflow/dags/pipeline.py.
